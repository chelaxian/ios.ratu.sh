# Проверка CC-твиков — 2026-10-20

Обновления: CCSSH 1.2.0, CCMCP 1.2.0, CCFRIDA 1.1.0, FuGapCC 0.5.1. CCVPN не изменён.

## Исправления

- Выключенная плитка показывает SSH/MCP/FRIDA белым без префиксов; включённая сохраняет оранжевый/синий/красный текст на белом фоне.
- Ошибка выполнения больше не становится состоянием «выключено». Источник индикации — ответ помощника о фактическом состоянии, а уведомление только запрашивает новую проверку.
- Все нажатия выполняются последовательно, включая нажатия во время проверки или предыдущего переключения. Удалены отбрасывание по `_busy` и задержка 0,6 с между тапами.
- Проверка открытой плитки каждые 0,5 с, вне CC — каждые 10 с. Статус не включает и не выключает службу. Неизвестное состояние не заменяет последнее подтверждённое.
- Временный отказ `posix_spawn` EBADEXEC повторяется до четырёх попыток. Повторяется только не начавшийся запуск; уже выполненное действие повторно не отправляется.
- Ожидание дочерних команд ограничено. Убраны избыточные вызовы launchctl; вместо чтения пути каждого процесса используется один снимок KERN_PROC_ALL с проверкой пути подходящих процессов.
- Перед остановкой запрещается перезапуск службы; оставшиеся процессы завершаются до bootout, чтобы не ждать завершения клиентских соединений внутри launchd.
- FuGapCC: политика строки состояния действует только в активном CC; изменения объединены в один проход; добавлены защита восстановления и сброс флага через @finally, проверка значений настроек, снимок ключей weak-map. Убрана подмена частных assertion-объектов. Для видимости строки состояния используются ограниченные активным CC публичные UIView setters без рекурсивного вызова собственного setter.

## Проверено

Устройство: iPhone15,3, iOS 17.0, Dopamine 3.0.10. Сборка macOS/Xcode: commit `0097a8f859365e331788ab37a8fe719f76c55156`, Actions `39421374195` — PASS. Все устанавливаемые Mach-O имеют arm64e PTRAUTH subtype 0x80000002, подпись и rootless-размещение; пакетная архитектура iphoneos-arm64. WSL использовался только для предварительной компиляции.

- PASS: установка четырёх пакетов, загрузка модулей, отсутствие safe mode.
- PASS: шесть реальных вызовов обработчика тапов MCP; два из них разделены 10 мс, ещё один отправлен во время status. Все шесть переходов выполнены, конечный статус ON, очередь пуста. В финальной сборке одиночное выключение MCP ≈0,45–0,48 с; включение ≈1,05–1,16 с. Это наблюдаемые значения, не гарантия нулевой задержки на любом устройстве.
- PASS: изменение MCP через помощник вне CC отображается как OFF/ON с правильными цветами. Сбой запуска и занятая проверка не создают ложный OFF.
- PASS: инъекция двух отказов запуска status (EBADEXEC), успешная третья попытка, состояние MCP остаётся ON, надпись MCP без `!`.
- PASS: физические касания SSH, внешняя проверка порта 2222: OFF ≈0,84 с, ON ≈0,54 с (включая транспорт теста), снимки белой/оранжевой надписи.
- PASS: физические касания FRIDA, независимая проверка списка процессов: OFF — ни одного frida-server; ON — новый PID. Прямой вызов помощника: OFF ≈0,27 с, ON ≈0,45 с. Снимки белой/красной надписи.
- PASS: FuGapCC сохраняет заданный пользователем отступ 45 pt, прокрутку, возвращает исходный inset 114 pt после закрытия CC; строка состояния снова видима. SpringBoard продолжает работать.
- Исходные состояния SSH/MCP/Frida ON восстановлены.

## Границы проверки

iOS 16 / Dopamine — NOT TESTED на реальном устройстве. Изменения FuGapCC профилактические: без crash log причина конкретного safe mode не установлена. Landscape, конфликты с произвольными сторонними модификациями CC и SSH localhost fallback в этом выпуске не проверялись.
