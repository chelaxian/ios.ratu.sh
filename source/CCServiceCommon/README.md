# Модули Control Center для Dopamine

- FuGapCC 0.5.0: com.ratush.ccgapcloser.
- CCSSH 1.1.0: com.ratush.ccopenssh.
- CCVPN (on/off/auto) 1.1.0: com.ratush.ccvpnonoffauto.
- CCMCP 1.1.0: com.ratush.catmcpcc.
- CCFRIDA 1.0.0: com.ratush.ccfrida.

Идентификаторы старых пакетов сохранены для обновления через APT. Имена bundle/фильтров также сохранены для существующей конфигурации CCSupport.

## Служебные переключатели

Module.m и Helper.m каждого пакета используют общий код в этой папке. Интерфейс запускает только фиксированные команды status/toggle/on/off. Привилегированный помощник проверяет root, сериализует операции отдельной блокировкой и запускает фиксированный launchctl с очищенным окружением. Пароль sudo не нужен. Отдельного постоянно работающего наблюдателя нет. Состояние перечитывается каждые пять секунд; ошибка не рисуется как успешное выключение.

Учитываются user/501 и system. OFF делает disable/bootout и завершает только процессы нужной службы с исполняемым файлом внутри активного /var/jb. ON включает и регистрирует штатный plist. Исходные plists не переименовываются. Frida проверяется и по TCP 27042, и по процессам. CCMCP управляет com.catmcp.server и сохраняет enabled в настройках CatMCP; дополнительные RootHide-фиксы не требуются.

CCSSH сохраняет порты, ключи и настройки аутентификации. Обычный OFF полностью закрывает SSH. Запасное ограничение входа через localhost применяется только при неудаче остановки; плитка показывает SSH·L. Оригинал sshd_config хранится в /var/jb/var/lib/ratu-cc/sshd_config.original и возвращается при ON. Не удаляйте эту копию до восстановления доступа.

Команды на телефоне: /var/jb/usr/bin/ccopenssh on|off|status; /var/jb/usr/bin/ccfrida on|off|status; /var/jb/usr/bin/catmcpcchelper on|off|status. При установке helpers получают root:wheel и 4755. Установка служебных плиток сама не меняет состояние управляемых служб.

## VPN

Короткий тап переключает выбранный системный профиль VPN, длинный — AUTO. При OFF отключается on-demand этого профиля, чтобы он не подключился сразу обратно. AUTO использует on-demand при наличии правил и дополнительное переподключение с паузой 15 секунд. Начальное значение on-demand сохраняется и восстанавливается при выключении AUTO длинным тапом.

Защита памяти применяется только к расширению с providerBundleIdentifier выбранного профиля. Повышается приоритет и устанавливается нефатальный лимит памяти не ниже 1024 MB. Исходные параметры возвращаются при выходе из AUTO, смене профиля и штатной остановке помощника. Общесистемная нехватка памяти всё равно может завершить VPN; абсолютная неуязвимость к jetsam не обещается. Источник ABI: https://github.com/apple-oss-distributions/xnu/blob/xnu-10002.1.13/bsd/sys/kern_memorystatus.h .

## Сборка и проверка

.github/workflows/build-cc-suite.yml собирает все пять DEB на macOS-14/Xcode и проверяет пакетную архитектуру iphoneos-arm64, подпись, зависимости и arm64e subtype 0x80000002. Предварительная WSL-сборка в этой сессии недоступна: WSL не ответил за ограниченное время.

Сборка, установка и поведение — отдельные этапы. Результаты живой проверки записываются в VALIDATION.md. Публикация выполняется только после проверки кандидата; файл Packages и DEB должны содержать одну версию, публичный файл проверяется по SHA256.
