# Демоны iOS

Управление отдельными службами launchd на iOS 17.0 / Dopamine rootless.

Мастер-переключатель находится на главной странице. Отдельные страницы: «Пресеты», «Демоны» и «Пресеты в пункте управления». Последняя позволяет выбрать встроенные и свои наборы для меню CC.

Короткое нажатие плитки включает или выключает мастер. Долгое нажатие открывает только выбранные пользователем пресеты. Смена пресета при выключенном мастере сохраняет выбор, не отключая службы.

«Базовый» отключает analyticsd, aggregated, dprivacyd, rtcreportingd, businessservicesd, progressd, nanoregistryd и wcd. Это условный набор для устройства без Apple Watch, без Messages for Business и ClassKit; он ограничивает диагностику. «Базовый + фотоанализ» дополнительно отключает photoanalysisd, mediaanalysisd и mediaanalysisd.service. «Только фотоанализ» управляет этими тремя службами. Остальные наборы: диагностика, службы часов, персонализация и индивидуальный набор.

Переключатели демонов означают «отключать в наборе». Под каждым пунктом отображаются реальные запрет запуска и загрузка службы. Отсутствие процесса у разрешённой службы нормально: многие службы запускаются по запросу.

Управляющая служба от root сохраняет исходные состояния до изменений, использует disable + bootout и проверяет результат. Выключение мастера и удаление пакета восстанавливают сохранённые состояния. Чужие первоначальные отключения сохраняются. Проект не меняет системные plist и не отключает критические службы связи, интерфейса, jailbreak или SSH.

Запреты launchd могут сохраняться после перезапуска iPhone. Перед работой без jailbreak выключите мастер. После обычной перезагрузки для управления снова требуется активировать Dopamine.

Пути:

- Состояние для интерфейса: `/var/mobile/Library/Preferences/com.ratush.daemonpresets.status.plist`.
- Журнал исходных состояний: `/var/jb/var/lib/ratu-daemon-presets/state.plist`, доступен только root.
- Управляющая служба: `/var/jb/usr/libexec/ratu-daemonpresetsd`.

Команда восстановления от root:

```sh
/var/jb/usr/libexec/ratu-daemonpresetsd --command off
```

Сборка: Theos, SDK 16.5, macOS/Xcode, `make clean package FINALPACKAGE=1`. Пакет `iphoneos-arm64`; интерфейс содержит arm64/arm64e. Проверка актуального arm64e ABI выполняется в CI. Сборки интерфейса из Linux/WSL не предназначены для установки в системные процессы.

Версия 1.0.1 исправляет ошибочный вызов contentViewController: на проверенном iOS 17 используется contentViewControllerForContext:. Версия 1.0.0 не предназначена для публикации.

Идеи исходных проектов: [DaemonDisabler level3tjg](https://github.com/level3tjg/DaemonDisabler) и [DaemonDisabler ringoju1ce](https://github.com/ringoju1ce/DaemonDisabler). Здесь реализован отдельный rootless пакет с журналом восстановления; методы отключения температурного контроля и SparseRestore не используются.

Свои пресеты: сохранение текущего состава под названием, удаление свайпом влево по строке. До 32 записей. Удаление активного пресета сохраняет текущие службы как индивидуальный набор и убирает удалённый пункт из CC.

Импорт и экспорт: файл JSON через «Файлы» и меню «Поделиться». Формат `{"schema":1,"presets":[{"name":"Название","jobs":["com.apple.tipsd"]}]}`. При импорте проверяется весь документ: неизвестные и защищённые службы отклоняются без частичного добавления. Импорт не меняет мастер и активный состав. Экспортируется текущий набор либо все свои пресеты.

Каталог состоит из 27 управляемых служб и справочного списка установленных launchd plist этого устройства. Справочный список формируется при открытии из системных и rootless каталогов, содержит поиск, заблокированные переключатели и синие кнопки ⓘ. Критические и непроверенные различаются в подсказках. Недоступные приложениям встроенные job, не имеющие plist в этих каталогах, не заявляются частью полного списка.

По результатам разбора Cappd/Appcd добавлен выборочный пресет: tipsd, videosubscriptionsd, nanobackupd. Он ограничивает Советы, данные ТВ-провайдера и резервное копирование Apple Watch. askpermissiond доступен отдельно и нужен для семейных запросов покупок. Агрессивные списки старых пакетов не перенесены: см. LEGACY-AUDIT.md.

Версия 1.1.4 сохраняет файлы экспорта в `/var/mobile/Documents/DaemonPresets` и предлагает перенос JSON через буфер обмена. При импорте из буфера чтение происходит только после нажатия пользователем. Парсер справочного каталога освобождает промежуточные данные после каждого файла.

Версия 1.2.0 показывает фактический физический расход RAM процессов рядом с отключаемыми и критическими службами. У отключённых служб сохраняется замер перед отключением; главный счётчик суммирует подтверждённо завершённые процессы один раз по PID и времени запуска. Выключенный мастер показывает 0 МБ. Это оценка устранённого расхода, а не измерение прироста свободной памяти iOS. Незамеренные службы отмечаются «нет данных». Значения обновляются при открытии страниц и переключениях; отдельного постоянно работающего опроса нет. МБ = 1 000 000 байт.
