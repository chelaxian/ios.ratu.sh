# Offloader 1.0.3 — iOS 17 / Dopamine rootless

Полная самостоятельная реализация функций Offloader. Закрытый бинарник 0.0.6 и старые исправляющие dylib не включены. Сохраняются идентификатор пакета и существующие домены настроек.

## Функции

| Пункт | Реализация |
|---|---|
| Выгрузить приложение | Действие в контекстном меню установленного приложения, которое iOS считает выгружаемым; подтверждение; штатный InstallCoordination сохраняет документы и данные |
| Удалить приложение | Показывает/скрывает штатное действие удаления; подтверждение и ограничения остаются у iOS |
| Изменить экран Домой | Показывает/скрывает штатное действие редактирования |
| Защита приложений | Поиск по имени/идентификатору, переключатель для каждого приложения; защита блокирует ручную и автоматическую выгрузку через девять API InstallCoordination |
| Уже выгруженные приложения | Не получают повторное действие выгрузки; сохраняют штатную загрузку из облака |
| Папки, виджеты, веб-клипы | Сохраняют свои исходные меню |
| Настройки | Действуют при следующем открытии меню без respring; выбранные отсутствующие/выгруженные приложения сохраняются в списке защиты |

Русские и английские подписи выбираются по языку iOS. Чужие действия приложений сохраняются; фильтрация не заменяет удаление собственной командой.

## Установка

Источник: https://ios.ratu.sh/ · пакет: `com.level3tjg.offloader` · версия: `1.0.3` · архитектура пакета: `iphoneos-arm64`.

После установки перезапустите SpringBoard и закройте Настройки через переключатель приложений. Для загрузки новой защиты в уже работающий `appstored` нужен его следующий запуск; полный перезапуск телефона с повторной активацией Dopamine обеспечивает загрузку всех трёх целевых процессов. До этого старый процесс `appstored` может продолжать работать со старой версией защиты.

Если используете Choicy, разрешите `Offloader` для SpringBoard и Настроек, `OffloaderGuard` для SpringBoard, Настроек и `appstored`. Ограничения других твиков менять не требуется.

При обновлении dpkg заменяет файлы прежнего пакета. Конфликтующие отдельно установленные `com.ratush.offloader*fix` объявлены в control, чтобы старые перехваты не оставались одновременно с новой реализацией. `libMRYIPC` и AltList новой версии не нужны.

Для выгрузки используется привилегированный штатный процесс Настроек. Настройки открываются сразу после подтверждения, чтобы iOS не заморозила принятую операцию. Результат показывается в Настройках. Команда имеет UUID и срок 45 секунд; повторное выполнение после перезапуска Настроек запрещено. Операция выполняется вне главного потока, результат проверяется по LaunchServices. Ошибка или отсутствие подтверждения показываются пользователю.

Защита хранится атомарно в `/var/mobile/Library/Preferences/com.ratush.offloader.protection-snapshot.plist` и отражается в старом CFPreferences-домене. Файл снимка не является CFPreferences-доменом: его никто не записывает одновременно через cfprefsd. Root-процесс читает выбор mobile, а не собственные defaults. Если старые настройки ещё не перенесены, используется мобильный CFPreferences-домен.

## Сборка и проверки

```sh
THEOS="$HOME/theos" make clean package FINALPACKAGE=1
python3 tests/inspect_deb.py packages/*.deb
```

Устанавливаемый пакет собирается в `.github/workflows/build-offloader-rootless.yml` на macOS/Xcode. Три бинарника содержат arm64 и современный arm64e (`0x80000002`). Проверяются реальные подписанные страницы Mach-O, зависимости и rootless-размещение. `build-preflight.sh` на WSL служит предварительной проверкой компиляции; его arm64e-пакет не предназначен для установки.

CI отдельно выполняет тесты общих функций/защиты на macOS и тесты UIKit-меню в изолированном iOS 17 Simulator. Это не проверка запуска SpringBoard, прав доступа Настроек или автоматической выгрузки на настоящем Dopamine.

**Устройство не использовалось:** по запрету владельца отсутствовали обращения к телефону, установка, respring и чтение его состояния. Проверка фактической выгрузки/повторной установки, всех переключателей, защиты в Настройках → Хранилище iPhone и фоновой автоматической выгрузки остаётся владельцу. Отсутствие крашей на физическом iOS 17.0 не объявляется подтверждённым.

## Исправления 1.0.1

Панель зарегистрирована как контроллер PreferenceLoader (isController). Действие выгрузки добавляется через actionProvider реальной UIContextMenuConfiguration; штатные действия и настройки меню сохраняются.

## Исправления 1.0.2

В InstallCoordination передаётся допустимый DemotionReason 1. iOS 17 отвергает прежнее значение 0; проверка native helper теперь отдельно проверяет причину, ожидание удаления и сохранение проверки удаляемости.

## Исправления 1.0.3

Настройки запускаются активно, а не замороженными. Проверяется успешность запуска; уже принятое задание не остаётся ждать пробуждения Settings. Тест проверяет suspended=NO и обработку отказа запуска.
