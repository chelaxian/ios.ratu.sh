# App Split VPN

Раздельная маршрутизация приложений через активный системный VPN на iOS с Dopamine.

**Статус: 0.2.0 установлен и работает на iOS 17.0 (Dopamine) с активным CT: служба определяет имя VPN, применяет правила, журнал и переключатель Пункта управления работают.** На активном CT проверены оба режима на Safari и отдельном CLI-процессе: в BYPASS Safari шёл напрямую, в TUNNEL ONLY Safari шёл через VPN, а другой процесс напрямую. После SIGKILL служба восстановила правила, после отключения сняла их.

- TUNNEL ONLY: только приложения из списка VPN сохраняют маршрут через системный VPN; остальные идут напрямую.
- BYPASS: приложения из DIRECT идут напрямую; остальные сохраняют системную VPN-маршрутизацию.
- Настройки: Settings → Tweaks → App Split VPN. Два независимых списка с поиском, буквенным индексом, группировкой, сортировкой, фильтрами и счётчиками. Импорт/экспорт списков — JSON; отсутствующие приложения сохраняются для переустановки.
- Выгруженные и удалённые iOS приложения не имеют исполняемого файла: правила для них пропускаются в обоих режимах, статус показывает число недоступных. Если приложение установлено, но его сетевую идентичность не удаётся определить, TUNNEL ONLY блокирует обновление правил во избежание прямого выхода.
- В 0.2.0 добавлены выбор RU/EN, цветовая индикация статуса, журнал изменений правил и переключатель в Пункте управления. Журнал показывает выбранный путь по правилам, а не измеренные сетевые соединения. Имя VPN показывается только если активную конфигурацию удалось определить однозначно.
- Сортировка по трафику и экранному времени отсутствует: твик не собирает per-app трафик, а Screen Time требует отдельного разрешения и не даёт этому твику простой надёжной статистики. Страна разработчика по bundle ID не выводится. Истечение профиля показывается только при читаемом embedded.mobileprovision; отзыв сертификата не определяется.
- Индикатор в статус-баре отложен: для него нужна инъекция в системный интерфейс iOS 17 с отдельной проверкой совместимости и стабильности; работающий VPN и SpringBoard не следует подвергать риску ради неподтверждённого значка.
- Твик выключен по умолчанию. Существующие соединения после смены правил могут требовать переоткрытия приложения.

Не привязан к CT и не содержит адаптеров отдельных VPN-протоколов. Собственные исключения и маршруты VPN продолжают действовать. Это не kill switch. Управляемые per-app VPN, запрет обхода и несколько одновременно активных VPN требуют отдельной проверки.

Пока не проверены: другой VPN-клиент, LTE, DNS, IPv6, UDP/QUIC, фоновые запросы и сложные профили NetworkExtension. Поэтому совместимость с любым без исключения VPN не заявляется как подтверждённая. При активном VPN начинайте с одного тестового приложения и сверяйте его внешний IP.
