# Точка передачи: перед GitHub Actions

Пользователь просит GPT-6 Astra закончить сложную часть и остановиться перед сборкой самого твика. Следующая более дешёвая модель продолжает после переключения пользователем.

Рабочая папка: D:\ChatGPT\CT\ios-split-routing
Репозиторий: chelaxian/ios.ratu.sh
Ветка: feature/app-split-vpn
Пакет: com.ratush.appsplitvpn 0.1.0, rootless iphoneos-arm64.

Сначала читать ARCHITECTURE.md полностью. Механизм двух режимов проверен на живом телефоне через NECP с curl/wget. Исходники службы и панели готовы к macOS-сборке; локальный arm64 preflight прошёл. Сам DEB ещё не собирался, не устанавливался, не публиковался. Проверки GUI, DNS, UDP/IPv6 и второго VPN остаются приёмочными воротами; они могут потребовать исправлений, поэтому не считать дальнейшую работу гарантированно чисто механической.

Workflow build-app-split-vpn.yml теперь ТОЛЬКО workflow_dispatch. Не делать новую сборку, пока пользователь не переключил модель/не велел продолжать. Пример после возобновления:

```powershell
gh workflow run build-app-split-vpn.yml -R chelaxian/ios.ratu.sh --ref feature/app-split-vpn
```

Поскольку workflow ещё отсутствует в main, имя может не разрешиться через API. В таком случае использовать ID из gh workflow list --all/API либо разместить workflow в main отдельным проверенным коммитом без публикации пакета. Не менять публичный APT индекс до прохождения установки и проверки.

SSH alias iphone. Пароль не выводить: на телефоне cat ~/sudoi.pass | sudo -S -p sudo: <команда>. Каждую привилегированную команду удобно выполнять отдельным SSH-вызовом; кавычки пустого -p в Windows в этой сессии искажали команду. Не копировать данные пользователя в Git.

Сборка CLI требует явного -Cadhoc; подробности в ARCHITECTURE.md. Самостоятельная служба использует только собственные правила NECP. Не добавлять инъекцию во все приложения и не переписывать клиент CT.
