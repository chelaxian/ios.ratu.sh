# Проверка Appabetical / Dopamine — 5 октября 2026

Устройство: iPhone 14 Pro Max, iOS 17.0 (21A329), Dopamine 3.0.10, ElleKit 1.2. Версия перед работой: `com.ratush.appabetical 1.0.16+rootless4`. Новая реализация: 2.0.0; функциональные проверки выполнены на сборках beta2/beta3 с тем же кодом.

## Исправления

- Сортировка переставляет живые иконки через API `SBFolder`, вместо редактирования устаревшего `IconState.plist`.
- Перед снимком раскладки вызывается `saveIconStateIfNeeded`: `iconState` сам по себе читает сохранённую модель и не отражает несохранённые перемещения.
- Сгруженные приложения определяются и при отсутствующем `SBApplication`: проверены 105 таких иконок.
- Переписаны все настройки, оба языка, обработка строк панели, команды и уведомления.
- Сохранение, перезапись, восстановление и удаление пресетов выполняет SpringBoard. Настройки ждут ответ с UUID и показывают ошибки записи/таймауты.
- Путь активного CCSupport-файла определяется через `CCSModuleSettingsProvider._configurationFileURL`; на устройстве он находится в overlay Dopamine, а не в обычном `/var/mobile`.
- Восстановление использует штатное хранилище SpringBoard, контрольную точку и проверку после перезапуска. Автосортировка пропускается один раз, чтобы не изменить восстановленный пресет.
- Unicode-фильтрация эмодзи сохраняет настоящие буквы вне BMP. Стабильное сравнение учитывает числа и диакритику.

## Обнаруженные конфликты и пределы проверки

AppData вызвал SIGABRT при построении кэша иконок после respring (`SpringBoard-2026-10-05-143537.ips`, `ADCustomIconPathIfExists`, `mdict_rehashd`). После краша SpringBoard запускался без Appabetical. По выбору пользователя AppData оставлен в `deniedTweaks` только для `com.apple.springboard` в Choicy. Исключение подтверждено в активном хранилище CFPreferences Dopamine.

Также записан отдельный краш DockLibrary при обработке жеста (`SpringBoard-2026-10-05-145815.ips`, `valueForUndefinedKey`); его пакет и настройки в этой работе не изменялись.

Во время одного CC-теста появился новый модуль `com.ratush.daemonpresets.cc`. Проверка восстановления корректно не объявила полный успех при расхождении с прежним снимком; повторная проверка с актуальным составом модулей прошла. Полное равенство старого пресета после установки новых приложений/модулей нельзя обещать. При изменении инвентаря иконок восстановление отменяется.

Пробная полная перезагрузка модели через Frida вызвала watchdog; этот способ не используется новой сортировкой. Сортировка использует проверенные перестановки, восстановление — атомарное сохранение штатного store с перезапуском.

Подтверждены функции на указанном устройстве и версии iOS. Эти результаты не являются гарантией совместимости с любым сторонним твиком и любой версией iOS.
